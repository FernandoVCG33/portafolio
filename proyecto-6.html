01

Moda para desarrolladores en una vitrina digital adaptable

Bajo el concepto de «Código de Estilo», el proyecto plantea una tienda especializada en poleras para programadores que rinden homenaje a los lenguajes y tecnologías más populares del desarrollo web: VueJS, AngularJS, React, Redux, Node.js, SASS, HTML5, GitHub, Bulma, TypeScript, Drupal, JavaScript, GraphQL y WordPress.

El objetivo técnico principal fue consolidar el dominio de HTML, CSS y Responsive Design estructurando un escaparate de productos limpio, navegación clara entre las vistas de Tienda y Nosotros, y grillas adaptables que mantuvieran la proporción visual en cualquier tamaño de pantalla.

“ EL RETO DE MAQUETACIÓN

“¿Cómo estructurar un catálogo de productos y la identidad de una tienda para desarrolladores aplicando HTML semántico, CSS Grid y diseño responsivo?”

02

Proceso y estructura del sitio

01

Estructura semántica en HTML5 y navegación

Organización limpia del encabezado con el logotipo de FrontEnd Store, barra de navegación principal (Tienda / Nosotros), grillas de productos, bloques informativos y pie de página.

02

Catálogo «Nuestros Productos» con CSS Grid

Construcción de la grilla de 14 poleras temáticas (VueJS, AngularJS, React, Redux, Node, SASS, HTML, GitHub, Bulma, TS, Drupal, JS, GraphQL y WordPress, cada una con su nombre y precio de 40 Bs.) combinada con bloques gráficos destacados dentro del flujo del grid.

03

Sección «Nosotros» · Historia de Código de Estilo

Diseño de una vista editorial que presenta la historia de «Código de Estilo» acompañada de fotografía destacada (polera Redux), transmitiendo cómo la tienda fusiona creatividad, humor y pasión por el código.

04

Bloque «¿Por qué comprar con nosotros?»

Maquetación de los cuatro pilares de valor de la tienda: El Mejor Precio (ofertas de alto valor), Para Devs (colección exclusiva pensada en desarrolladores), Envío Gratis (entrega sin cargo extra) y La Mejor Calidad (materiales premium y duraderos).

05

Responsive Design y despliegue en Netlify

Uso de media queries, unidades relativas y variables CSS para adaptar el número de columnas del catálogo y los bloques informativos desde teléfonos móviles hasta monitores de escritorio.
